# Dal — Roadmap

## Done (hackathon prototype)

- [x] Marketplace with four directions: Courses, Work with an Expert, Community, Ideas & Analytics
- [x] Expert ratings per direction; forecast statistics separate from teaching reviews
- [x] Video lessons in order, progress, refunds by the rules
- [x] Questions and comments under each lesson with expert answers
- [x] Course reviews only after completion, one per course, immutable
- [x] Consultation booking from a weekly schedule, clubs and chats with subscriptions, paid ideas
- [x] Dal Studio for experts, moderation queue, expert verification
- [x] Forecasts anchored on Solana Devnet (Memo + Phantom) with public verification
- [x] Course reviews anchored on Solana by their authors
- [x] "Connect wallet" button with Devnet balance and test SOL airdrop
- [x] Full backend running in the browser for the Vercel demo
- [x] English and Russian interface

## Next

- [ ] Card and Kaspi payments with receipts, expert payouts

- [ ] Automatic forecast resolution with Pyth price feeds instead of manual moderator input
- [ ] Non-transferable course completion certificates on Solana
- [ ] Club passes as on-chain tokens valid for the subscription period
- [ ] New lesson questions in Dal Studio and notifications for experts
- [ ] Mainnet anchoring
- [ ] Kazakh interface, servers in Kazakhstan
