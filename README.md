# Dal

Платформа обучения инвестициям: сайт для учеников, Dal Studio для экспертов и модерация.

## Как запустить (рабочая версия с сервером)

1. Установите Node.js 24 LTS с [nodejs.org](https://nodejs.org).
2. В PowerShell:
   ```powershell
   cd "$env:USERPROFILE\Desktop\DAL\server"
   npm start
   ```
3. Откройте в браузере:
   - <http://localhost:4000/> — сайт для учеников;
   - <http://localhost:4000/login.html> — вход и регистрация;
   - <http://localhost:4000/studio.html> — Dal Studio (эксперт) и модерация (модератор);
   - <http://localhost:4000/docs> — документация API.

Демо-аккаунты (пароль у всех `dal-demo-2026`): `student@dal.local`, `aliya@dal.local`, `moderator@dal.local`. Подробнее — в `server/README.md`.

Все данные (аккаунты, курсы, видео, прогресс, прогнозы) хранятся в папке `server` на этом компьютере. Сайты нужно открывать именно через адрес `http://localhost:4000`, а не двойным щелчком по `index.html`.

## Демо-версии без сервера

`Dal.html` и `Studio.html` — автономные макеты, открываются двойным щелчком. Данные в них вымышленные и хранятся только в браузере. Их исходники лежат в папке `demo/`, пересобрать — `python build.py`.

## Что можно посмотреть

- **Барабан разделов:** Главная, Курсы, Работа с экспертом, Сообщество, Идеи и аналитика. Движение мыши и колёсико показывают следующий раздел, клик открывает его, стрелки переключают сразу.
- **Вход и регистрация** ученика или эксперта. Меню аватарки: «В процессе», моё обучение, избранное, рейтинг, профиль, настройки, выход.
- **Ученик:** каталог курсов из базы, бесплатные уроки до покупки, покупка без оплаты, уроки с видео по порядку и прогресс, отзыв, возврат.
- **Эксперт в Dal Studio:** курсы от черновика до каталога, загрузка видео с прогрессом, обложки, прогнозы, ученики, ответы на отзывы и жалобы, доход, профиль.
- **Модератор в Dal Studio:** проверка и одобрение курсов с просмотром видео, жалобы на отзывы, изменения профилей, подтверждение экспертов, итоги прогнозов.
- Светлая и тёмная темы, выбор акцента, отключение анимации.

## Граница прототипа

Это рабочий прототип для обсуждения с командой, а не готовый финансовый сервис. Демо-эксперты, цены, отзывы и прогнозы вымышлены. Портреты иллюстративные и не изображают реальных экспертов. Сервис не даёт инвестиционных рекомендаций.

Работает: вход и роли, курсы с видео, покупка без оплаты, прогресс, отзывы, прогнозы, модерация, правила эксперта на сервере. Пока нет оплаты и выплат, источника котировок, уведомлений, записи в Solana. «Работа с экспертом», «Сообщество» и материалы идей пока в демо-режиме: их данные хранятся только в браузере.

## Соответствие схеме

1. Курсы: Для новичков; Для продвинутых; Вебинары и практикумы.
2. Работа с экспертом: Разовая консультация; Индивидуальные занятия; Длительное сопровождение.
3. Сообщество: Закрытый клуб; Чат с экспертом и участниками.
4. Идеи и аналитика: Сигналы; Инвестиционные идеи; Обзоры рынка и компаний.
5. Личный кабинет (меню аватарки): «В процессе», обучение с прогрессом, избранное, рейтинги, профиль, настройки.

Клик по направлению открывает отдельный каталог на всю основную область страницы. Имя автора ведёт в профиль, название продукта в подробности. Рейтинг обучения отделён от исходов прогнозов. Общая оценка эксперта — средняя оценка учеников по его курсам.

## Для разработчика

- `index.html`, `app.js`: сайт для учеников, подключённый к серверу.
- `login.html`, `login.js`: вход и регистрация.
- `studio.html`, `studio.js`, `studio.css`: Dal Studio и модерация, подключённые к серверу.
- `api.js`: общий клиент API (токен входа, загрузка файлов с прогрессом).
- `server/`: бэкенд, см. `server/README.md`.
- `demo/`: исходники автономных демо-версий.
- `styles.css`: адаптивный интерфейс, темы и анимация типографического барабана.
- `data.js`: демонстрационные режимы, категории, эксперты и продукты.
- `app.js`: навигация по hash, состояние, экранные шаблоны, взаимодействия и Canvas 2D переход.
- `assets/`: локальные фотографии, шрифты и Lucide.
- `build.py`: собирает автономные `Dal.html` и `Studio.html` из исходников (`python build.py`).

Реализация без сборки и фреймворка выбрана для простого просмотра и передачи. Для продуктовой версии можно перенести компоненты в стек команды. Любую серверную проверку покупки, прав доступа, отзывов и прогресса нужно реализовать независимо от этого клиентского состояния.

Видео и обычные пользовательские данные предполагаются вне блокчейна. Возможный реестр прогнозов Solana требует отдельного проектирования: неизменяемые условия, источник цены, срок и правило проверки, полномочия обновления, идентичность автора. Текущий макет не решает эти вопросы и не обещает невозможности мошенничества.

## Dal Studio (кабинет эксперта)

- Курсы: черновик → модерация → каталог → скрыт. Чек-лист перед отправкой на модерацию, предпросмотр глазами ученика.
- Видео: перетаскивание или выбор файла (MP4, MOV, WEBM, до 4 ГБ), индикатор загрузки, длительность, просмотр, замена. В прототипе видео хранится в браузере (IndexedDB) и никуда не отправляется.
- Прогнозы: форма с проверками, предпросмотр условия, подтверждение. После публикации прогноз нельзя изменить или удалить, можно только добавить комментарий.
- Отзывы: публичный ответ и жалоба модерации; удалить отзыв нельзя.
- Права эксперта: страница «Права» — предложение для обсуждения; правила уже соблюдаются в интерфейсе.
- Исходники: `studio.html`, `studio.css`, `studio-data.js` (демо-данные и права), `studio.js`.
