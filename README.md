# Dal: интерактивный прототип

Два сайта в одной папке:

- `Dal.html` — сайт для учеников.
- `Studio.html` — Dal Studio, кабинет инвестора-эксперта: курсы с загрузкой видео, прогнозы, ученики, отзывы, доход, профиль и права эксперта.

Оба файла автономные: открываются двойным щелчком, интернет не нужен.

Для простого просмотра откройте `Dal.html` двойным щелчком в современном браузере. Это автономная версия: фотографии, шрифт и код встроены в один файл. Установка, интернет и аккаунт не требуются.

Для разработки используйте `index.html` и отдельные исходники. В этом случае папка `assets` должна оставаться рядом с сайтом. При передаче исходников распакуйте архив целиком.

## Что можно посмотреть

- Барабан разделов: Главная, Курсы, Работа с экспертом, Сообщество, Идеи и аналитика. «Главная» показывает обзор всех четырёх направлений.
- Левой боковой панели нет. Личное пространство (Моё обучение, Избранное, Рейтинг экспертов, профиль, настройки) и блок «В процессе» открываются по клику на аватарку.
- Барабан режимов: движение мыши и колёсико показывают следующий вариант; нажатие по названию открывает его. Стрелки, точки и горизонтальное касание переключают режим сразу. На клавиатуре стрелки меняют предварительный выбор, Enter подтверждает.
- Быстрый цветовой переход, светлая и тёмная темы, выбор акцента и отключение анимации. Системная настройка уменьшения движения учитывается автоматически.
- Все категории из схемы пользователя, каталоги с поиском и сортировкой, предложения и страницы экспертов.
- Избранное, демонстрационная покупка, список доступных материалов, учебный экран и прогресс.
- Меню аватара, редактирование профиля, рейтинг по направлениям и отдельная демонстрационная статистика прогнозов.
- Локальные отзывы, демонстрационный чат, выбор времени встречи. Ничего не отправляется другому человеку.

## Граница прототипа

Это визуальный прототип для обсуждения с командой, не готовый финансовый сервис. Профили, достижения, цены, отзывы, прогнозы и показатели вымышлены. Портреты иллюстративные и не идентифицируют реальных экспертов. Демо не даёт инвестиционных рекомендаций.

Нет серверной авторизации, реальных видеоуроков, оплаты, записи встреч, уведомлений, проверки прав доступа или записи в Solana. Локальная «покупка» только показывает пользовательский путь. Данные сохраняются в браузере с помощью localStorage и могут быть изменены самим пользователем. Сброс доступен в настройках.

Уроки содержат пример учебного текста, а не полный курс. Повторяющийся текст предназначен для демонстрации навигации и прогресса. Графики прогнозов иллюстративные, не котировки.

## Соответствие схеме

1. Курсы: Для новичков; Для продвинутых; Вебинары и практикумы.
2. Работа с экспертом: Разовая консультация; Индивидуальные занятия; Длительное сопровождение.
3. Сообщество: Закрытый клуб; Чат с экспертом и участниками.
4. Идеи и аналитика: Сигналы; Инвестиционные идеи; Обзоры рынка и компаний.
5. Личный кабинет (меню аватарки): «В процессе», обучение с прогрессом, избранное, рейтинги, профиль, настройки.

Клик по направлению открывает отдельный каталог на всю основную область страницы. Имя автора ведёт в профиль, название продукта в подробности. Рейтинг обучения отделён от исходов прогнозов. Общая оценка эксперта в макете является средним арифметическим четырёх демонстрационных оценок направлений.

## Для разработчика

- `index.html`: общий каркас приложения.
- `styles.css`: адаптивный интерфейс, темы и анимация типографического барабана.
- `data.js`: демонстрационные режимы, категории, эксперты и продукты.
- `app.js`: навигация по hash, состояние, экранные шаблоны, взаимодействия и Canvas 2D переход.
- `assets/`: локальные фотографии, шрифты и Lucide.
- `build.py`: собирает автономные `Dal.html` и `Studio.html` из исходников (`python build.py`).

Реализация без сборки и фреймворка выбрана для простого просмотра и передачи. Для продуктовой версии можно перенести компоненты в стек команды. Любую серверную проверку покупки, прав доступа, отзывов и прогресса нужно реализовать независимо от этого клиентского состояния.

Видео и обычные пользовательские данные предполагаются вне блокчейна. Возможный реестр прогнозов Solana требует отдельного проектирования: неизменяемые условия, источник цены, срок и правило проверки, полномочия обновления, идентичность автора. Текущий макет не решает эти вопросы и не обещает невозможности мошенничества.

## Dal Studio (кабинет эксперта)

- Курсы: черновик → модерация → каталог → скрыт. Чек-лист перед отправкой на модерацию, предпросмотр глазами ученика.
- Видео: перетаскивание или выбор файла (MP4, MOV, WEBM, до 4 ГБ), индикатор загрузки, длительность, просмотр, замена. В прототипе видео хранится в браузере (IndexedDB) и никуда не отправляется.
- Прогнозы: форма с проверками, предпросмотр условия, подтверждение. После публикации прогноз нельзя изменить или удалить, можно только добавить комментарий.
- Отзывы: публичный ответ и жалоба модерации; удалить отзыв нельзя.
- Права эксперта: страница «Права» — предложение для обсуждения; правила уже соблюдаются в интерфейсе.
- Исходники: `studio.html`, `studio.css`, `studio-data.js` (демо-данные и права), `studio.js`.
